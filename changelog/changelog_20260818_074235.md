# Accreditation logo marquee

Date: 2026-08-18

## Changed

- Replaced the static accreditation logo grid with a seamless right-to-left animated strip.
- Removed the white cards, borders and other visible containers around each mark.
- Added a translucent monochrome, softened-contrast and subtle-blur treatment to create a sandblasted-glass appearance on the navy background.
- Added edge fading and responsive logo sizing for a continuous full-width presentation.
- Paused the marquee on hover and keyboard focus, hid the duplicate animation track from assistive technology, and retained the site's reduced-motion behavior.

## Follow-up correction

- Replaced the blend-mode approximation with an SVG luminance-to-alpha filter so the white JPEG backgrounds are actually removed instead of appearing as grey rectangles.
- Reduced the strip height and increased the marquee speed so it reads as a continuous moving line rather than a static logo block.
- Moved the marquee from global CSS animation to the existing runtime animation library so site-wide CSS motion overrides cannot leave the track stationary.
- Corrected the mobile layout from a wrapped two-column block to a fixed-height, single-row strip.
- Replaced the unsupported mobile SVG filter with direct inversion and screen blending so the raster backgrounds disappear in Chrome.
