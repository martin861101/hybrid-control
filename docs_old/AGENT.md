AGENT PROMPT — HYBRID CONTROL CORPORATION WEBSITE REDESIGN

You are a senior product designer, brand designer, UX architect and frontend engineer.

Your task is to completely redesign and rebuild the Hybrid Control Corporation website:

Reference website: https://www.hybridcontrol.co.za/

Build it as a premium, world-class industrial technology and engineering website using a modern React architecture.

Do not simply reskin or reproduce the existing website.

Study the existing website carefully, understand the company, services, industries, products, projects, positioning and existing brand identity, then reinterpret it as a modern digital experience suitable for a serious African engineering, industrial automation and systems integration company operating at enterprise level.

---

1. TECHNOLOGY

Build using:

- React 19+
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion / Motion for React
- Lucide React icons
- React Router
- Component-driven architecture
- Responsive CSS
- Modern semantic HTML
- Accessible UI patterns

The site must run with:

npm install
npm run dev

Avoid unnecessary dependencies.

Do not introduce a backend unless genuinely required.

---

2. PRIMARY OBJECTIVE

The current website contains valuable information but visually feels like a traditional corporate/engineering website.

The redesign should reposition Hybrid Control Corporation as a sophisticated modern engineering and industrial technology organisation.

The immediate impression should be:

Engineering precision. Industrial intelligence. Infrastructure at scale.

The site should feel credible enough for organisations operating in:

- Water and wastewater
- Utilities
- Energy
- Oil & Gas
- Mining
- Manufacturing
- Industrial infrastructure
- Municipal infrastructure
- Process automation
- Telemetry
- Electrical engineering

The visual benchmark is not a typical local SME website.

Think closer to the digital presence of a global industrial technology company, engineering consultancy or infrastructure organisation.

- correct obvious issues
